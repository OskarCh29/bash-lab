# Bash Lab

A hands-on Bash and Linux learning repository.

This repository documents my journey from basic shell commands
to practical DevOps automation.

## Learning Path

1. Bash fundamentals
2. File and directory management
3. Conditions and loops
4. Functions and error handling
5. Text processing
6. Linux administration
7. Git automation
8. Docker automation
9. CI/CD
10. Practical projects

## Goals

- Become comfortable working in Linux terminal
- Write Bash scripts from scratch
- Automate repetitive tasks
- Understand processes, permissions and networking
- Automate Docker workflows
- Build a foundation for CI/CD and DevOps
