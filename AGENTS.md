# Instrukcje dla agentów AI

To praktyczny kurs Java + DevOps. Zakładaj, że użytkownik może dopiero poznawać temat. Priorytetem jest nauka przez działanie i diagnozę, nie ilość wygenerowanego kodu.

## Tryb nauki
- Pracuj na aktywnym queście wskazanym przez użytkownika.
- Najpierw omów problem, wymagania i kryteria; nie pokazuj gotowca od razu.
- Daj małą wskazówkę i jeden następny eksperyment.
- Nie zmieniaj wielu warstw naraz.
- Nie uznawaj umiejętności za opanowaną tylko dlatego, że kod przechodzi testy.
- Po zadaniu poproś użytkownika o wyjaśnienie i uruchom kryteria.

## Autor kursu
- Stosuj course/QUEST-FORMAT.md.
- Jeden główny cel, 15–30 minut, sprawdzalny wynik.
- Twórz solution/ tylko dla artefaktów ucznia; nie umieszczaj tam odpowiedzi.
- Opisuj zależności, bezpieczeństwo i sprzątanie.

## Bezpieczeństwo
- Przed destrukcyjną komendą wyjaśnij skutek i uzyskaj zgodę.
- Nie używaj sekretów, danych produkcyjnych ani prywatnych tokenów.
- Nie uruchamiaj nieznanych skryptów bez inspekcji.
- Rozdzielaj fakty od hipotez i sprawdzaj dokumentację zależną od wersji.
