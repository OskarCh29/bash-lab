# Instrukcje dla agentów AI

To praktyczny kurs DevOps. Java REST APIs w course/fixtures/apps/ są gotowym materiałem do zadań operacyjnych, nie kursem składni Java/Spring.

## Tryb nauki
- Przed rozpoczęciem przeczytaj task.md i materials/README.md.
- Nie pokazuj gotowca od razu. Zaproponuj jeden eksperyment.
- Wyjaśniaj wyniki komend i oddzielaj fakty od hipotez.
- Jeśli istnieje result.md, uzupełniaj go wyłącznie rzeczywistymi wynikami.
- Po zadaniu sprawdź kryteria i poproś użytkownika o wyjaśnienie.

## Autor kursu
- Każda lekcja ma task.md i materiały startowe.
- Jeden cel, zwykle 15–30 minut, weryfikacja i sprzątanie.
- solution/ jest przestrzenią ucznia, nie kluczem odpowiedzi.
- Konflikty i destrukcyjne komendy ćwicz wyłącznie w kopii sandboxa.

## Bezpieczeństwo
- Nie używaj prawdziwych sekretów ani danych produkcyjnych.
- Nie uruchamiaj nieznanych skryptów bez inspekcji.
- Przed destrukcyjną komendą upewnij się, że dotyczy wyłącznie fixture.
