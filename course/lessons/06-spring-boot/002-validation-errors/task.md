# T-0026 — Walidacja i błędy API

> Moduł: Spring Boot — API i dane · Poziom 3 · 30 min

## Misja

API ma odrzucać zadania bez tytułu i zwracać przewidywalne błędy.

## Cel nauki

Poznaj walidację, kody HTTP i obsługę błędów.

## Zadania

1. Zdefiniuj reguły żądania
2. Dodaj walidację serwerową
3. Ustal odpowiedzi dla błędów i not found
4. Przetestuj przez curl

## Kryteria zaliczenia

- Błędne dane nie tworzą zasobu
- Kody HTTP pasują do problemu
- Stack trace nie trafia do klienta

## Weryfikacja

Sprawdź poprawne żądanie, pusty tytuł i brakujący ID

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Waliduj dane na granicy API
2. **Kierunek:** Szczegóły techniczne zapisuj w logach
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?

## Porządkowanie

Używaj lokalnych danych
