# T-0017 — Poznaj gotową aplikację Java

> Moduł: Aplikacje przykładowe — Java jako materiał · Poziom 1 · 20 min

## Misja

Przed konteneryzacją ustal, jaki proces uruchamiasz, jakie endpointy udostępnia i jakiej konfiguracji potrzebuje.

## Cel nauki

Czytaj gotową aplikację jako artefakt operacyjny, bez nauki składni Java.

## Materiały

- [Materiały tej lekcji](materials/README.md)
- Wspólne fixture: course/fixtures/apps/
- Uzupełnij result.md rzeczywistymi wynikami terminala.

## Zadania

1. Otwórz README wspólnych aplikacji
2. Znajdź endpointy, porty i zmienne środowiskowe
3. Uzupełnij result.md na podstawie kodu i dokumentacji
4. Nie zmieniaj źródeł fixture

## Kryteria zaliczenia

- Wymieniasz endpointy porty i zmienne obu usług
- Rozróżniasz kod od konfiguracji runtime
- Nie zmieniłeś wspólnego fixture

## Weryfikacja

Porównaj result.md z kontraktem opisanym w README fixture

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Szukaj createContext, PORT i PROFILE_API_URL
2. **Kierunek:** Najpierw przeczytaj README, potem potwierdź informacje w kodzie
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala. Poproś o wyjaśnienie i jeden kolejny eksperyment zamiast od razu o rozwiązanie.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie: co zrobiłeś samodzielnie, gdzie potrzebowałeś pomocy, jaki błąd popełniłeś i co warto powtórzyć.

## Porządkowanie

Zadanie inspekcyjne; nie zmieniaj plików fixture
