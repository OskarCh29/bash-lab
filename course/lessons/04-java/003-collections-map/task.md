# T-0019 — Kolekcje i mapa częstości

> Moduł: Java — fundamenty języka · Poziom 2 · 30 min

## Misja

Policz wystąpienia i wykryj duplikaty bez zagnieżdżonych pętli.

## Cel nauki

Dobierz List, Set i Map; zrozum equals oraz hashCode.

## Zadania

1. Przygotuj listę z powtórzeniami
2. Zbuduj mapę liczby wystąpień
3. Przetestuj wielkość liter
4. Wyjaśnij equals/hashCode

## Kryteria zaliczenia

- Wynik jest poprawny
- Pusta lista działa
- Uzasadniasz wybór kolekcji

## Weryfikacja

Przetestuj listę bez duplikatów i z powtórzeniami

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Map<T,Integer> pasuje do liczenia
2. **Kierunek:** XOR nie zastępuje ogólnie kolekcji do wykrywania duplikatów
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.
