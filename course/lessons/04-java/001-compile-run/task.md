# T-0017 — Skompiluj pierwszą klasę Java

> Moduł: Java — fundamenty języka · Poziom 1 · 25 min

## Misja

Napisz mały program CLI, skompiluj go i uruchom bez frameworka.

## Cel nauki

Zrozum plik źródłowy, main, javac i JVM.

## Zadania

1. Utwórz klasę z main
2. Skompiluj przez javac i uruchom przez java
3. Obsłuż argument
4. Wprowadź błąd składni i odczytaj komunikat

## Kryteria zaliczenia

- Program działa z terminala
- Rozróżniasz błąd kompilacji i wykonania
- Rozumiesz nazwę pliku i klasy

## Weryfikacja

Skompiluj i uruchom program w katalogu ćwiczenia

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Kompilator tworzy bytecode
2. **Kierunek:** Czytaj pierwszą lokalizację błędu
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?
