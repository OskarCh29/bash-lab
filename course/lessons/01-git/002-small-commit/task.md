# T-0006 — Zrób mały, czytelny commit

> Moduł: Git — bezpieczna praca ze zmianami · Poziom 1 · 25 min

## Misja

Dwie zmiany są w katalogu roboczym, ale tylko jedna należy do zadania.

## Cel nauki

Ćwicz selektywny staging i komunikaty opisujące intencję.

## Zadania

1. Wprowadź dwie nieszkodliwe zmiany
2. Dodaj do staging tylko jedną
3. Obejrzyj staged diff i utwórz commit
4. Sprawdź git show --stat

## Kryteria zaliczenia

- Commit zawiera tylko zamierzoną zmianę
- Komunikat jest konkretny
- Druga zmiana pozostaje poza commitem

## Weryfikacja

Sprawdź git show --stat i git status

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Dodawaj konkretne ścieżki
2. **Kierunek:** Commit to migawka staging area
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?

## Porządkowanie

Pracuj na osobnym branchu
