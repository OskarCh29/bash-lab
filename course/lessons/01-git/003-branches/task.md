# T-0007 — Branch, zmiana i merge

> Moduł: Git — bezpieczna praca ze zmianami · Poziom 2 · 25 min

## Misja

Zrealizuj zmianę na osobnej gałęzi, a potem połącz ją z gałęzią bazową.

## Cel nauki

Rozumiej branch, commit i merge.

## Zadania

1. Utwórz branch
2. Wprowadź zmianę i commit
3. Porównaj historię gałęzi
4. Wykonaj merge

## Kryteria zaliczenia

- Wiesz, na której gałęzi pracujesz
- Zmiana nie ginie
- Wyjaśniasz rolę brancha

## Weryfikacja

Sprawdź git log --oneline --graph --decorate

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** git switch -c tworzy i wybiera branch
2. **Kierunek:** Przed merge sprawdź niezatwierdzone zmiany
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?

## Porządkowanie

Usuń wyłącznie swój branch po weryfikacji
