# T-0054 — Uratuj niezacommitowaną pracę przez stash

> Moduł: Git — bezpieczna praca ze zmianami · Poziom 2 · 25 min

## Misja

Dostajesz pilną poprawkę, ale masz niedokończoną pracę, której nie chcesz commitować.

## Cel nauki

Ćwicz git stash, podgląd stash i odtworzenie zmian.

## Materiały

- [Materiały tej lekcji](materials/README.md)
- Wspólne fixture: course/fixtures/git-taskboard/

## Zadania

1. Zmień dwa pliki fixture
2. Odłóż zmiany na stash z opisem
3. Przełącz branch i wróć
4. Odtwórz stash i sprawdź diff

## Kryteria zaliczenia

- Umiesz odłożyć i odtworzyć zmiany
- Wiesz, czym różni się apply od pop
- Żadna zmiana nie zginęła

## Weryfikacja

Porównaj git status i git stash list przed i po

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Najpierw sprawdź, co odkładasz
2. **Kierunek:** Stash nie zastępuje trwałego commita
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala. Poproś o wyjaśnienie i jeden kolejny eksperyment zamiast od razu o rozwiązanie.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie: co zrobiłeś samodzielnie, gdzie potrzebowałeś pomocy, jaki błąd popełniłeś i co warto powtórzyć.
