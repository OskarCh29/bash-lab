# T-0024 — Zbuduj i uruchom JAR

> Moduł: Java — Maven i testy · Poziom 2 · 25 min

## Misja

Przekaż aplikację bez wymogu posiadania IDE i Twojego katalogu roboczego.

## Cel nauki

Rozumiej źródła, artefakt i runtime.

## Zadania

1. Skonfiguruj pakowanie JAR
2. Zbuduj od czystego stanu
3. Uruchom artefakt
4. Udokumentuj wersję Javy i komendę

## Kryteria zaliczenia

- Build działa z terminala
- Potrafisz znaleźć artefakt
- Instrukcja działa poza IDE

## Weryfikacja

Uruchom mvn clean package i sprawdź target

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Nie każdy JAR zawiera zależności
2. **Kierunek:** Ustal wersję Javy jawnie
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?
