# T-0023 — Test regresyjny przed poprawką

> Moduł: Java — Maven i testy · Poziom 3 · 30 min

## Misja

Odtwórz zgłoszony błąd testem, a potem napraw kod bez osłabiania asercji.

## Cel nauki

Używaj testu jako reprodukcji i ochrony przed powrotem błędu.

## Zadania

1. Wprowadź kontrolowany błąd
2. Napisz test, który nie przejdzie
3. Popraw implementację minimalnie
4. Uruchom wszystkie testy

## Kryteria zaliczenia

- Test wykrywa błąd przed poprawką
- Poprawka jest mała
- Wcześniejsze testy przechodzą

## Weryfikacja

Zapisz wynik przed i po naprawie

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Test opisuje zachowanie, nie implementację
2. **Kierunek:** Nie usuwaj asercji dla zielonego builda
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?

## Porządkowanie

Nie pozostawiaj błędu celowego
