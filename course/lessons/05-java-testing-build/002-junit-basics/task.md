# T-0022 — Pierwsze testy JUnit

> Moduł: Java — Maven i testy · Poziom 2 · 30 min

## Misja

Dodaj testy chroniące reguły biznesowe i przypadki brzegowe.

## Cel nauki

Poznaj Arrange-Act-Assert i automatyczną weryfikację.

## Zadania

1. Wybierz metodę z jednoznacznym wynikiem
2. Napisz test zwykły i dwa brzegowe
3. Uruchom testy Maven
4. Zepsuj zachowanie na chwilę i sprawdź test

## Kryteria zaliczenia

- Testy są deterministyczne
- Każdy test sprawdza konkretne zachowanie
- Raport pokazuje wynik

## Weryfikacja

Uruchom mvn test i potwierdź porażkę testu z błędną implementacją

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Nazwa testu opisuje warunek i rezultat
2. **Kierunek:** Test ma zawieść, gdy zachowanie jest błędne
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?

## Porządkowanie

Przywróć implementację
