# T-0029 — Obraz a kontener

> Moduł: Docker — od obrazu do aplikacji · Poziom 1 · 20 min

## Misja

Uruchom obraz testowy i prześledź cykl życia kontenera.

## Cel nauki

Rozróżnij obraz od uruchomionej instancji.

## Zadania

1. Uruchom nazwany kontener testowy
2. Sprawdź status logi i metadane
3. Zatrzymaj i usuń kontener
4. Opisz, co zostaje

## Kryteria zaliczenia

- Wyjaśniasz obraz i kontener
- Potrafisz sprawdzić stan i logi
- Nie usuwasz zasobów innych projektów

## Weryfikacja

Użyj docker ps -a, docker images i docker logs

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Obraz jest szablonem, kontener instancją
2. **Kierunek:** Nazwij kontener testowy
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?

## Porządkowanie

Usuń tylko swój kontener
