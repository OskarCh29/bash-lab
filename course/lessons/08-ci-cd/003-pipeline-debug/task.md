# T-0036 — Napraw zepsuty pipeline

> Moduł: CI/CD — automatyczne sprawdzanie · Poziom 3 · 30 min

## Misja

CI nie przechodzi, choć build lokalny działa. Znajdź pierwszy istotny błąd.

## Cel nauki

Ćwicz logi i różnice środowiska.

## Zadania

1. Zasymuluj błąd na branchu
2. Znajdź istotny komunikat
3. Porównaj JDK katalog roboczy zmienne i komendę
4. Napraw i opisz przyczynę

## Kryteria zaliczenia

- Diagnoza odwołuje się do logu
- Poprawka nie wyłącza testów
- Pipeline przechodzi

## Weryfikacja

Zapisz nieudany krok i potwierdź zielony run

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Zachowaj pierwszy log przed rerun
2. **Kierunek:** Porównaj komendę CI z lokalną
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?

## Porządkowanie

Nie pozostawiaj wyłączonych testów
