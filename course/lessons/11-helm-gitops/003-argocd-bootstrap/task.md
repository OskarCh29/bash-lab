# T-0048 — Pierwsze wdrożenie przez Argo CD

> Moduł: Helm i GitOps — Argo CD · Poziom 4 · 30 min

## Misja

Ustal stan aplikacji w Git i obserwuj pierwszą synchronizację Argo CD.

## Cel nauki

Poznaj Application source destination Synced i Healthy.

## Zadania

1. Uruchom Argo CD lokalnie według dokumentacji
2. Zdefiniuj Application
3. Sprawdź sync i health
4. Zmień bezpieczną wartość w Git

## Kryteria zaliczenia

- Źródło i ścieżka są poprawne
- Rozróżniasz Synced i Healthy
- Zmiana jest deklaratywna

## Weryfikacja

Sprawdź status Argo CD i zasoby kubectl

## Podpowiedzi — otwieraj stopniowo

1. **Mała wskazówka:** Zweryfikuj URL i ścieżkę
2. **Kierunek:** Sync i health to różne statusy
3. **Gdy nadal utkniesz:** pokaż AI konkretny wynik z terminala; poproś o wyjaśnienie i jeden mały eksperyment, nie gotową odpowiedź.

## Raport po zadaniu

Zapisz w prywatnym Obsidianie:
- Co wykonałem samodzielnie?
- Gdzie potrzebowałem pomocy?
- Jaki błąd popełniłem i co było przyczyną?
- Czy umiem odtworzyć rozwiązanie bez kopiowania?
- Co powinienem powtórzyć?

## Porządkowanie

Nie commituj tokenów
