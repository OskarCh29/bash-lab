# Wspólne materiały kursowe

Fixture to fikcyjne dane i kod do ćwiczeń, nie gotowe odpowiedzi.
- terminal/: ukryte pliki i metadane.
- linux/logs/: logi do analizy.
- git-taskboard/: źródła do komend Git i prawdziwego konfliktu.
- bash/: listy ścieżek i katalogi do backupu.
- apps/: task-api i profile-api w standardowym JDK.
- docker/, ci/, observability/, kubernetes/: startery do diagnozy.

Kopiuj fixture przed edycją. Nie dodawaj prawdziwych sekretów.
