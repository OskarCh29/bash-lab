# Java + DevOps Quest Lab

Kurs zawiera 52 krótkie zadania. Rozwiązujesz praktyczne problemy w terminalu, zmieniasz pliki, uruchamiasz aplikację, czytasz logi i potwierdzasz wynik testami.

## Jak pracować
- Przechodź questy w zalecanej kolejności.
- Jedna sesja to zwykle jeden quest — 15–30 minut.
- Nie proś AI o gotowca na początku; gdy utkniesz, poproś o najmniejszy eksperyment.
- solution/ jest przestrzenią ucznia, nie katalogiem odpowiedzi.
- Quest jest zaliczony, gdy rezultat został zweryfikowany i umiesz wyjaśnić, dlaczego działa.
- Prywatny postęp zapisuj w Obsidianie, nie w publicznym repozytorium.

## Moduły
1. **Start tutaj — terminal i diagnoza** — Poznaj repozytorium i diagnozuj problemy. Folder: `lessons/00-start-here/`.
2. **Git — bezpieczna praca ze zmianami** — Status, staging, branche i konflikty. Folder: `lessons/01-git/`.
3. **Linux — pliki, procesy i sieć** — Ścieżki, uprawnienia, procesy i połączenia. Folder: `lessons/02-linux/`.
4. **Bash — automatyzacja** — Argumenty, warunki, funkcje i skrypty. Folder: `lessons/03-bash/`.
5. **Java — fundamenty języka** — Typy, metody, kolekcje i wyjątki. Folder: `lessons/04-java/`.
6. **Java — Maven i testy** — Build, JUnit i regresje. Folder: `lessons/05-java-testing-build/`.
7. **Spring Boot — API i dane** — REST, walidacja, PostgreSQL i health. Folder: `lessons/06-spring-boot/`.
8. **Docker — od obrazu do aplikacji** — Dockerfile, Compose, sieci i wolumeny. Folder: `lessons/07-docker-compose/`.
9. **CI/CD — automatyczne sprawdzanie** — GitHub Actions, testy i artefakty. Folder: `lessons/08-ci-cd/`.
10. **Observability — Prometheus i Grafana** — Metryki, dashboardy i incydenty. Folder: `lessons/09-observability/`.
11. **Kubernetes — wdrożenie i diagnoza** — Minikube, Deployment, Service, probes i rollout. Folder: `lessons/10-kubernetes/`.
12. **Helm i GitOps — Argo CD** — Chart, wartości środowiskowe i synchronizacja. Folder: `lessons/11-helm-gitops/`.
13. **Capstone — od kodu do klastra** — Integracja, incydent i dokumentacja. Folder: `lessons/12-capstone/`.

## Wspólny projekt QuestBoard
Podczas modułów Java budujesz API z walidacją i PostgreSQL. Następnie rozwijasz tę samą aplikację przez Docker Compose, CI, Prometheus/Grafana, Minikube, Helm i Argo CD. Nie przechodź dalej, jeśli nie potrafisz zweryfikować poprzedniej warstwy.

## Pomoc AI
> Nie pokazuj gotowego rozwiązania. Wyjaśnij, co wynika z mojego konkretnego wyniku, i zaproponuj jeden mały eksperyment do wykonania.

Po ukończeniu poproś AI o recenzję kryteriów i pytania sprawdzające. Wygenerowany kod nie jest dowodem — uruchom test lub komendę.
